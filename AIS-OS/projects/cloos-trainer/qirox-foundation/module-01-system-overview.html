Section 1

The QIROX Robot Family

CLOOS QIROX robots are purpose-built for industrial welding. The QRC series covers three size classes — 320, 350, and 410 — defined by reach radius and payload capacity. All share the same 6-axis articulated arm design and the same CAROLA programming language.

QRC model family — QRC 320, 350, and 410 shown side by side. Larger number = greater reach and payload. Source: PA_Qirox_QS2.12
Six-axis articulated arm. Axes A1–A6 are named sequentially from base to wrist. Source: PA_Qirox_QS2.12
ModelReach RadiusPayloadTypical Use
QRC 320~1,600 mmUp to 6 kgLight-duty single-torch welding, compact cells
QRC 350~2,000 mmUp to 8 kgStandard torch + seam tracking sensor
QRC 410~2,500 mmUp to 10 kgExtended reach, positioner cells, heavy torch setups
Tip
The model number encodes the arm reach class, not an arbitrary product code. Always check the actual technical data sheet for the certified working range of the specific robot serial number on-site.
Section 2

Robot System Architecture

Every QIROX cell consists of four primary system elements. Understanding what each one does — and what connects to what — is essential before touching any part of the system.

Complete QIROX system block diagram showing robot mechanics, controller, teach pendant, and peripheral connections. Source: PA_Qirox_QS2.12
ComponentFunctionPhysical Location
Robot Mechanics (QRC)6-axis articulated arm — executes all motion commands. Carries the welding torch at the A6 flange.Mounted to floor, column, or gantry inside cell
Robot Controller (QC2)The brain — processes programs, controls servo drives, manages safety I/O, and communicates with all peripherals.Free-standing cabinet, typically outside safety fence
Teach Pendant (QPHG 2)Operator interface — all programming, jogging, mode selection, and status monitoring happens here.Handheld, connected to controller via cable or wireless
QINEO Power SourceProvides the welding arc — controls wire feed, voltage, current, and shielding gas. Communicates with controller via QTI interface.Separate cabinet adjacent to cell
V7 manual system structure overview showing how robot mechanics, controller, positioner, and power source form a complete welding cell. Source: PA_Qirox_V7

The controller is the hub. Everything else — teach pendant, robot arm, power source, positioners, safety fence, PLC — connects back to it. If something is not working, the controller's logbook is always the first place to look.

Section 3

The Six Robot Axes

The QRC robot has six rotary axes labeled A1 through A6. Each axis has a defined positive and negative direction. Understanding the axis layout is the foundation for jogging, programming, and diagnosing motion faults.

Axis layout for a QIROX QRC robot. A1 rotates the base. A2/A3 control shoulder and elbow. A4–A6 are the wrist axes. Source: PA_Qirox_V7
  • A1
    Base rotation — Rotates the entire arm around the vertical mounting axis. Largest range of motion (~340°).
  • A2
    Shoulder — Pivots the upper arm forward and back relative to the base.
  • A3
    Elbow — Bends the forearm up and down. Combined with A2 defines reach height.
  • A4
    Wrist roll — Rotates the forearm around its own axis. Provides torch orientation twist.
  • A5
    Wrist bend — Tilts the wrist up/down. Primary torch angle axis.
  • A6
    Torch rotation — Final rotation at the flange. Fine-tunes approach angle for tight joint access.
Warning
Each axis has a software-defined working range limit. If a programmed position would exceed a limit, the controller raises a range error before executing the movement. Never attempt to force movement beyond displayed range limits — this indicates a programming or calibration issue, not a hardware problem to override.
Section 4

Working Range & Cell Layout Concepts

The working range is the 3D envelope within which the robot's Tool Center Point (TCP) can physically reach. It is bounded by both the mechanical limits of the arm and any software-defined safety zones configured for the cell.

Working range cross-section for a QRC-class robot. Unrestricted range (outer envelope), restricted range (software limits), and maximum area are all defined during commissioning. Source: PA_Qirox_V7
Range TypeDefinitionWho Sets It
Unrestricted Working RangeThe full mechanical envelope the robot can physically reach without any software restrictions.Fixed by hardware design
Restricted Working RangeThe portion of the envelope within software axis limits set at commissioning — the normal operating zone.Commissioning engineer
Maximum AreaThe outer boundary used for safety zone design — all personnel exclusion barriers must exceed this radius.Cell designer / safety engineer
Restricted AreaZones where motion is intentionally prohibited — e.g., near the operator station or fixture clamps.Commissioning engineer
Field Note
On customer sites, the programmed axis limits may be tighter than the mechanical limits to protect fixtures, positioners, or nearby equipment. Always check the axis limit values during commissioning before testing movements near boundaries.
